# 企业产品手册（演示文档）

> 本文件用于演示文档上传 → 解析 → 向量化 → RAG 检索的完整流程。

## 1. 产品简介

AgentHub 是一款企业级智能知识平台，内置多租户数据隔离、RAG 检索增强生成、
智能体编排与 MCP 工具调用能力，帮助企业快速构建私有化 AI 应用。

## 2. 退款政策

用户购买 SaaS 订阅服务后，7 天内可无条件全额退款；超过 7 天不足 30 天的，
按剩余服务时长比例退款；超过 30 天不予退款。退款申请请在控制台「工单中心」
提交，客服将在 2 个工作日内处理。

## 3. 数据安全

所有客户数据采用租户级隔离存储，向量数据与业务数据分库部署；
支持私有化交付，数据不出企业内网。

## 4. 部署方式

支持公有云 SaaS、私有化 Docker Compose、Kubernetes 三种部署形态，
其中 Docker Compose 一键启动包含 MySQL、PGVector、RocketMQ、MinIO 等全部依赖。
